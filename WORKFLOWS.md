# StoreFront Studio — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## Build a ten-image narrative

Give each image one job: introduction, key task, result or supporting feature. Use consistent hierarchy and device scale. Review the set in order and remove repeated claims. A smaller coherent sequence is more useful than ten nearly identical screens.

## Localize without clipping

Begin with verified in-app captures for the destination language. Adapt headlines for meaning instead of forcing the same word count. Check punctuation, reading order, line breaks and the relationship between the headline and visible UI. Review right-to-left languages in their actual direction.

## Check an upload batch

Keep a matrix of locale, device slot, image count and filename. Review every cell against exported assets before uploading. Afterward inspect the destination listing to confirm ordering and completeness. Never publish credentials or assume the most recently opened App Store Connect app is the intended target.
